# 小蛋留言板

一个轻量级、现代美观的**纯前端**留言板项目！

## 技术栈
- 原生 HTML + CSS + JavaScript（无后端依赖）
- 数据持久化：`localStorage`
- 响应式布局（移动端优先）
- 现代扁平卡片 UI

## 核心功能
- ✅ 发布留言（昵称 + 内容 + 板块）
- ✅ 留言实时上屏 + 点赞
- ✅ 板块分类筛选
- ✅ 字符计数提示
- ✅ 留言持久化（刷新不丢失）
- ✅ 初始示例留言
- ✅ 清空数据 / 重置示例
- ✅ 随机头像

## 运行方式

1. 创建一个新文件夹（例如 `F:\egaowangzhan`）
2. 在该文件夹中创建 3 个文件：
   - `留言板.html`
   - `style.css`
   - `script.js`
3. 将上面提供的 3 个文件分别保存到对应位置
4. 双击 `留言板.html` 即可打开
